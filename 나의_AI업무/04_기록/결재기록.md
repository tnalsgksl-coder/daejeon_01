## 결재-005 · FFmpeg 설치 (2026-11-02)
- 관련 업무: 업무-002 (영상 준비 · 영상 제작 모드)
- 캡틴 선택: "A. FFmpeg만"
- 분류: 설치 → 결재 대상 (`CLAUDE.md` 9번 · 17번). 설치하면 이 폴더 밖에 파일이 생겨서 AI는 직접 설치하지 않음(10번). 캡틴이 직접 하고 AI는 화면마다 안내(9번)
- 대상: FFmpeg (그림 · 소리 · 자막을 영상 파일로 묶는 무료 프로그램)
- 방법 (캡틴이 고름):
  - ① winget(윈도우에 들어 있는 프로그램 설치 도구)으로 한 줄 설치: `winget install --id Gyan.FFmpeg -e`. 단계가 적음. 캡틴 사용자 폴더(AppData) 안에 깔리고 어디서든 `ffmpeg`로 부를 수 있게 등록됨
  - ② 압축 파일을 받아 이 폴더 안(예: `06_도구/`)에 풀기: 폴더 밖에 깔리는 것 없음. 대신 단계가 많고, 도구 폴더를 `CLAUDE.md` 3번 표에 넣는 결재가 하나 더 필요
- 바꾸기 전 → 후: PC에 FFmpeg 없음(확인 전) → FFmpeg 있음. AI는 영상을 만들 때 `05_영상/` 안에서만 결과를 씀
- 받는 곳: gyan.dev가 만든 윈도우용 빌드 (ffmpeg.org의 다운로드 페이지가 안내하는 곳)
- 크기: 약 100~200MB로 알고 있음 (정확한 크기는 확인 못 함)
- 비용: 0원 (무료 프로그램)
- 위험: 처음 winget을 쓰면 약관 동의를 묻는 질문이 나올 수 있음 → 캡틴이 읽고 직접 판단(AI는 대신 답하지 않음). 저장 공간 여유는 미확인
- 되돌리는 법: ① 캡틴이 `winget uninstall --id Gyan.FFmpeg -e` 실행 ② 도구 폴더를 `04_기록/사본보관/`으로 옮김
- 이미 깔려 있으면: 설치하지 않고 이 결재는 '필요 없음'으로 닫음
- 캡틴 답: **승인 · 방법 ①** (2026-11-02, 캡틴 답 그대로: "① winget으로 승인")
- 실제 실행: **안 됨** (2026-11-02). 캡틴 터미널 화면 확인 결과:
  - `where.exe ffmpeg` → 못 찾음, `ffmpeg -version` → 인식 안 됨 (FFmpeg 없음)
  - `winget install --id Gyan.FFmpeg -e` 2번 → 'winget' 용어가 인식되지 않음. 설치 도구가 실행조차 안 돼서 PC에 바뀐 것 없음
  - AI는 다시 시도하지 않음 (12번). 승인 내용(방법 ①)은 그대로 열어 두고 캡틴 선택 대기
- 처리: 캡틴 "② 방식으로 바꾸기" → 결재-006으로 대체하고 닫음 (설치된 것 없음)
