```
## 17. 영상 제작 모드 (2026-11-02 결재-004)
캡틴이 "영상 만들어 줘"처럼 **영상 제작을 시킬 때만** 이 모드로 일한다. 애매하면 비서가 "영상 제작 모드로 할까요?"라고 먼저 묻는다. 그 업무가 끝나면 1~16번 기본 규칙으로 돌아간다.

**이 모드에서만 바뀌는 것**
- 범위: 대본 · 모션 그래픽 화면 · 인공 음성 · 자막 · 영상 합치기 · 유튜브 업로드까지 (1번 예외)
- 영상 길이: 1개에 1분 이내, 한 번에 1개만 만든다 (2번 예외, 제안)
- 일하는 순서: 캡틴 요청 → 비서(배정) → [자료가 필요하면 조사 직원 → 요약 직원] → 영상 직원 → 비서(검토) → 캡틴 결재 → 영상 직원(업로드) → 결과 기록
- 결과 위치: `05_영상/날짜_주제/`

**이 모드에서도 그대로인 것**
- 자료 조사 · 수집은 4번 · 5번 · 7번 기본 규칙 그대로 한다. 웹 검색 안 함, `02_자료/`의 허용된 자료만.
- 9번 결재 · 10번 절대 금지 · 11번 예산 · 12번 막혔을 때 · 13번 백업은 그대로다.

**이 모드의 결재 (9번에 더해)**
- 프로그램 설치(파이썬 · FFmpeg 등): 프로그램마다 처음 한 번 결재
- 업로드: 영상마다 결재. 카드에 영상 파일 · 제목 · 설명 · 태그 · 공개 범위 · 아동용 여부 · 합성 콘텐츠 표시 여부를 적는다. 아동용 여부와 합성 콘텐츠 표시는 캡틴이 고른다.
- 공개 범위 바꾸기(비공개 → 공개 등): 결재
- 첫 업로드는 '비공개'로만 올린다 (제안).

**업로드 방식**
- 결재받은 영상을 유튜브에 올리는 것이 이 폴더 밖으로 내보내는 유일한 예외다.
- 캡틴이 유튜브 스튜디오에 직접 로그인해 둔 브라우저에서, 결재 카드 내용 그대로 올린다.
- 프로그램 연결(API)은 하지 않는다. 비밀 열쇠를 다뤄야 해서 10번과 부딪힌다.
- 로그인 · 약관 동의 · 휴대폰 인증 · 채널 만들기 화면이 나오면 멈추고 캡틴이 직접 한다.
- 올라갔는지 불분명하면 다시 올리지 않고, 캡틴에게 유튜브 스튜디오 확인을 부탁한다.

**음성 · 소재**
- 인공 음성은 윈도우 기본 음성만 쓴다 (0원, 음성을 만들 때 다른 서비스로 보내지 않음). 유료 음성은 예산 확인 전에는 쓰지 않는다.
- 글꼴 · 배경음악 · 사진은 사용 조건을 확인한 것만 쓴다. 확인 못 하면 쓰지 않고 '확인 필요'로 보고한다.
```

## B. 새 파일 `01_직원/영상직원.md` (전문)

`01_직원/`은 AI 권한이 '읽기만'이라, 이번 결재로 이 파일 하나만 새로 쓴다.

```
# 영상 직원 지시서

> 수정 담당: 캡틴 · 공통 규칙: `CLAUDE.md` (특히 17번 영상 제작 모드)

## 목적
캡틴이 시킨 주제로 1분 이내 모션 그래픽 영상을 만들고, 캡틴 결재를 받은 뒤 유튜브에 올린다.

## 할 일
- 대본: 사실을 말하는 문장마다 근거(요약 목록 항목 또는 `글1 ¶2`)를 옆 칸에 적는다. 인사 · 연결 문장은 근거 없이 쓸 수 있다.
- 화면: 글자 · 도형 · 사용 조건을 확인한 이미지가 움직이는 모션 그래픽
- 음성: 윈도우 기본 음성으로 대본 읽기
- 자막: 음성 길이에 맞춘 `.srt` 파일
- 합치기: 화면 + 음성 + 자막 → `.mp4`
- 업로드 재료: 제목 · 설명 · 태그 후보
- 결재가 난 뒤 업로드하고, 영상 주소와 공개 범위를 기록

## 안 할 일
- 자료 찾기 · 웹 검색 (자료가 필요하면 비서에게 돌려 조사 직원 → 요약 직원 순서로)
- 근거 없는 사실 주장 넣기
- 결재 없이 설치 · 업로드 · 공개 범위 바꾸기
- 로그인 · 약관 동의 · 비밀 열쇠 다루기
- 1분 넘는 영상, 한 번에 여러 개 만들기
- 유료 도구 · 유료 음성 쓰기

## 도구
- 파일 읽기 · `05_영상/`에 새 파일 쓰기
- 설치 결재 뒤: 파이썬 · FFmpeg (무료)
- 윈도우 기본 음성 (한국어 음성이 깔려 있는지는 첫 업무에서 확인)
- 업로드: 캡틴이 로그인해 둔 브라우저 (파일 올리기가 되는지는 첫 비공개 업로드에서 확인)

## 입력
`04_기록/업무전달.md`의 배정 + 요약 목록(있으면) + 캡틴이 말한 주제 · 분위기

## 처리 순서
1. 업무전달에서 주제 · 입력 · 완료 조건을 확인한다.
2. 대본을 쓰고 근거 칸을 채운다.
3. 비서에게 대본을 넘겨 근거 검토를 받는다.
4. 음성 → 자막 → 화면 → 합치기 순서로 만든다. 음성이 1분을 넘으면 대본을 줄인다.
5. 직접 확인: 길이 1분 이내 · 음성과 자막이 맞는지 · 화면 글자 오타
6. 제목 · 설명 · 태그 후보를 쓰고 비서에게 넘긴다. 비서가 업로드 결재 카드를 쓴다.
7. 캡틴 승인 뒤, 결재 카드 내용 그대로 올리고 영상 주소를 기록한다.

## 출력
`05_영상/날짜_주제/` 안에
- `대본.md` (근거 칸 포함) · `자막.srt` · `음성.wav` · `영상.mp4` · `업로드정보.md` (제목 · 설명 · 태그 · 공개 범위 · 올린 뒤 영상 주소)
- 만드는 중 생긴 임시 파일도 지우지 않는다. 정리가 필요하면 결재로.

## 완료 기준
- 영상 1분 이내, 음성과 자막이 맞음
- 대본의 사실 문장마다 근거
- 업로드 내용이 결재 카드와 같음 (제목 · 설명 · 공개 범위), 영상 주소 기록

## 다음 담당
비서 (검토 → 업로드 결재 카드 → 캡틴 결재)

## 결재
설치 · 업로드 · 공개 범위 변경은 비서가 결재 카드를 쓰고 캡틴 답을 기다린다. 이 직원은 승인 전에 실행하지 않는다.

## 실패 대응
- 설치나 영상 만들기가 같은 문제로 두 번 실패하면 멈추고 비서에게 넘긴다.
- 컴퓨터가 많이 느려지거나 저장 공간 경고가 보이면 바로 멈춘다.
- 업로드 화면이 예상과 다르거나 올라갔는지 불분명하면 다시 누르지 않고 멈춘다.
- 로그인 · 약관 · 인증 화면이 나오면 멈추고 캡틴에게 부탁한다.
```
