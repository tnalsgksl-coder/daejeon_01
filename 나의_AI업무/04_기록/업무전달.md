# 업무 전달

> 수정 담당: 비서 · 직원끼리 일을 넘길 때 비서가 여기에 적어요. 새 업무는 맨 아래에 추가해요.

## 업무-001 · 첫 시험 (2026-11-02)
요청: 가상 글 3개 → 비교한 짧은 목록 1개, 항목마다 근거 위치, 빠진 핵심 없음 (Q30)

### ① 비서 → 조사 직원
- 입력: `02_자료/첫시험_가상글_1.md`(글1) · `02_자료/첫시험_가상글_2.md`(글2) · `02_자료/첫시험_가상글_3.md`(글3) — 가상 자료
- 출력: `03_결과/첫시험_조사메모.md`
- 완료 조건: 모든 문단 읽기 · 핵심마다 근거 위치와 원문 인용 · 비교 3칸 · 넘김 칸
- 주의: 웹 검색 안 함 · `02_자료/` 고치지 않음 · 폴더 밖 안 봄

### ② 조사 직원 → 비서 (받음)
- `03_결과/첫시험_조사메모.md` 받음. 완료 조건 4개 충족 확인.
- 넘겨받은 주의점: 글1 ¶4는 글쓴이 주장(따로 근거 없음) → 요약에 표시하도록 전달

### ③ 비서 → 요약 직원
- 입력: `03_결과/첫시험_조사메모.md` (근거 확인용으로 `02_자료/` 읽기 가능)
- 출력: `03_결과/첫시험_요약목록.md`
- 완료 조건: 핵심 12개 반영(또는 뺀 이유) · 모든 글머리에 근거 · 원문에 없는 말 없음 · 빈 줄 빼고 20줄 이내

### ④ 요약 직원 → 비서 (받음) · 비서 검토
- 1차 검토에서 고칠 점 1개: 글3 ¶2는 "목표를 한 줄로 적기"인데 "하나로 정한다"로 묶여 원문보다 넘침
  - 조사 직원: 조사 메모 비교 칸 수정 (재작업 1회)
  - 요약 직원: 요약 목록 첫 글머리 수정 (재작업 1회)
- 2차 검토 결과:

| 점검 | 결과 | 증거 |
|---|---|---|
| 1. 글머리마다 근거 위치 | 통과 | 글머리 10개 중 10개 |
| 2. 원문과 다른 말 없음 | 통과 | 인용 12개가 원문 해당 문단에 그대로 있음(기계 대조) + 요약 문장 10개 비서 대조 |
| 3. 핵심 모두 반영 | 통과 | 조사 메모 핵심 12개 중 12개 |
| 4. 다른 말 표시 | 통과 | 간격(25·5 ↔ 50·10), 휴대폰(다른 방 ↔ 알림 끄기) |
| 5. 추측·추천 없음 | 통과 | 글1 ¶4는 '글쓴이 주장'으로 표시 |
| 6. 빈 줄 빼고 20줄 이내 | 통과 | 16줄 |
| 7. 금지 행동 없음 | 통과 (자체 점검) | 폴더 밖 쓰기 · 웹 · 발송 · 삭제 없음 |

- 다음 담당: 캡틴 (결과 확인 후 합격 또는 수정)

### ⑤ 캡틴 판정
- 2026-11-02 · **합격** (캡틴 답: "네, 합격")
- 업무-001 끝. 다음: 실제로 쓸 자료 범위(Q22) · 웹 검색 허용 여부(Q12·Q13)를 캡틴에게 묻기

## 업무-002 · 영상 준비: FFmpeg (2026-11-02 · 영상 제작 모드)
요청: 영상 제작 준비. 캡틴 선택 "A. FFmpeg만" (파이썬은 설치 안 함)

### ① 비서
- 결재-005 작성: FFmpeg 설치, 방법 ①(winget) / ②(이 폴더 안에 압축 풀기)는 캡틴이 고름
- 설치는 캡틴이 직접 하고 비서가 화면마다 안내 (`CLAUDE.md` 9번 · 10번). AI는 설치 명령을 실행하지 않음
- 완료 조건: 캡틴 터미널에서 `ffmpeg -version`이 버전을 보여 줌 · 결과를 결재기록과 상황판에 적음
- 주의: 약관 동의 · 관리자 권한 창은 캡틴이 직접 판단. 이미 깔려 있으면 설치 건너뜀
- 다음: 캡틴이 영상 주제를 말하면 업무-003으로 첫 30초 시험 영상 (한국어 윈도우 음성 확인 · 비공개 업로드)
