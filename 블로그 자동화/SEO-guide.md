# 네이버 블로그 SEO 가이드 (2026년 11월 기준)

> **리서치 기준일**: 2026-11-02
> **용도**: 네이버 블로그 글을 쓰거나 검수할 때 참고하는 SEO 규칙. 다른 AI 에이전트가 이 파일만 보고 따라 할 수 있도록 규칙, 템플릿, 체크리스트로 정리했습니다.
> **함께 쓰는 파일**: `style-guide.md`(말투·문체). 같이 쓸 때 주의할 점은 9장에 정리했습니다.

## 읽기 전에: 근거 표시와 한계

네이버는 **글자 수, 키워드 횟수, 이미지 장수 같은 숫자 기준을 공식적으로 발표한 적이 없습니다.** 인터넷에 도는 "제목 30자", "1,500자", "사진 15장", "키워드 5회" 같은 공식은 모두 업계 경험칙입니다. 그래서 이 문서는 항목마다 근거 수준을 표시합니다.

| 표시 | 뜻 |
|---|---|
| **[공식]** | 네이버 공식 공지나 도움말에 있는 내용. 원문을 인용한 자료 2곳 이상에서 내용이 일치하는 것을 확인함 |
| **[업계]** | 마케팅 업계 통설이나 실무 권장. 공식 근거는 없음. 숫자는 출발점으로만 쓸 것 |
| **[법규]** | 공정거래위원회 지침 등 법적 기준 |

**한계**: 이번 리서치 환경에서는 네이버 도메인(blog.naver.com, help.naver.com)을 직접 열 수 없었습니다. 공식 내용은 원문을 인용한 기사·업계 자료와 재게시본으로 교차 확인했습니다. 중요한 결정 전에는 맨 아래 "출처"의 공식 링크를 직접 확인하세요.

## 0. 한눈에 보기: 핵심 원칙 10가지

1. **네이버 공식 5원칙**(2026-05): 직접 경험한 지식 · 일관된 주제 · 거짓 없는 진정성 · 읽기 쉬운 구조 · 최신성 유지 **[공식]**
2. 제목에는 **핵심 키워드를 한 번만**, 앞쪽에 넣습니다. 반복과 나열, 장식용 특수문자는 쓰지 않습니다. **[공식]+[업계]**
3. 제목과 본문 내용이 반드시 일치해야 합니다. 어긋나면 낚시성 스팸으로 분류됩니다. **[공식]**
4. 본문은 **소제목과 짧은 문단**으로 나누고, 결론을 앞에 둡니다(두괄식). **[공식]+[업계]**
5. 키워드 밀도에는 공식 기준이 없습니다. **문맥에 맞게 자연스럽게** 쓰고, 유의어와 연관어로 분산합니다. **[공식]+[업계]**
6. 이미지는 **본문 맥락에 맞는 직접 촬영·제작 이미지**를 쓰고, 이미지 속 핵심 정보는 텍스트로도 씁니다. **[공식]**
7. 해시태그는 **본문과 관련된 것만 5~10개**. 순위에 직접 영향을 준다는 근거는 없습니다. **[업계]**
8. **한 블로그는 한 주제**에 집중합니다(C-Rank). 글 하나하나는 경험과 충실한 정보로 채웁니다(D.I.A.). **[공식]**
9. AI는 써도 되지만, **사람이 검수하지 않은 대량 생성·자동 발행은 어뷰징**입니다. AI를 활용했다면 표시하는 것을 권장합니다. **[공식]**
10. 협찬·광고 글은 **제목이나 본문 첫 부분**에 경제적 이해관계를 밝힙니다. **[법규]**

## 2. 제목 작성 규칙

### 2-1. 네이버가 공식적으로 밝힌 것 [공식]
- 검색어는 **제목이나 본문에 들어 있어야** 검색 대상이 됩니다. (2016)
- 제목에 **같은 검색어를 여러 번 반복하면** 선호도가 떨어져 순위에서 밀립니다. (2016)
- 지역명이나 제품명을 **여러 개 나열하면** 내용을 파악하기 어렵고 품질이 낮아 보입니다. (2016)
- **의미 없는 특수문자나 유니코드 문자**로 눈길을 끄는 것은 어뷰징입니다. (2016) 다만 특수문자를 썼다는 이유만으로 정상적인 글이 제재받지는 않습니다.
- 본문과 **무관한 업체명이나 문구**를 넣으면 낚시성 문서로 분류될 수 있습니다. (2016)
- 제목은 "쉽게 잘 읽힐 수 있는 길이"로 쓰고, 동어 반복과 단어 나열은 권하지 않습니다. (2024, 네이버 블로그팀)
- **제목과 내용이 일치하지 않는 낚시성 제목**, **실제 명칭 대신 검색량이 많은 키워드를 쓰는 것**, **동일 키워드의 의도적 반복**은 스팸 유형입니다. (2026-07)

### 2-2. 실무 권장 [업계]

| 항목 | 권장 | 이유 |
|---|---|---|
| 길이 | **공백 포함 20~35자** | 모바일 검색 결과에서 한두 줄 안에 읽히는 길이. 공식 숫자 기준은 없음 |
| 핵심 키워드 위치 | **제목 앞쪽 절반 안**(가능하면 첫 단어) | 사람이 빨리 훑어볼 때 먼저 보임 |
| 핵심 키워드 횟수 | **1회** | 반복은 공식적으로 불리함 |

## 3. 본문 구조

### 3-1. 네이버가 공식적으로 밝힌 것 [공식]
- **읽기 쉬운 구조**: 제목, 소제목, 문단 나누기를 갖춥니다. (2026-05, 5원칙)
- **심층적 구성**: 주제에 도움이 될 만한 **충분한 길이의 정보와 분석**을 담습니다. 숫자 기준은 없습니다. (2024)
- **좋은 가독성**: 읽는 사람이 쉽게 읽고 이해할 수 있게 씁니다. (2024)
- **실전편 셀프 체크 5항목** (2026-06): 본문을 채우는 기준으로 그대로 씁니다.

| 셀프 체크 항목 | 본문에 들어가야 할 것 |
|---|---|
| ① 독자와 목적 | 누가, 어떤 상황에서 읽는 글인지. 동선·가격·소요 시간 같은 실용 정보 |
| ② 절차와 구체적 해결 과정 | 시간 순서의 과정, 실패와 수정, 수치 |
| ③ 대안과 비교 분석 | 직접 써 본 대안들의 장단점 비교, 상황별 선택지 |
| ④ 실제 적용 사례와 결과 | 환경과 기간을 밝힌 직접 측정 결과 |
| ⑤ 맥락에 맞는 이미지와 동영상 | 표·리스트·소제목으로 구조화, 본문과 직접 관련된 미디어 |

### 3-2. 실무 권장 [업계]

| 항목 | 권장 |
|---|---|
| 분량 | 정보성 글 기준 **공백 제외 2,000~5,000자**. 길이를 목표로 하지 말고, 셀프 체크 5항목을 채우면 자연히 이 범위가 됨. 300자 미만의 짧은 글 대량 발행은 피함 |
| 구성 비율 | **도입 10~15% / 본론 70~80% / 결론 10%** |
| 도입부 | 첫 3~5줄 안에 **이 글이 답하는 질문과 결론**을 제시(두괄식). 핵심 키워드 1회 |
| 소제목 | **본문 400~600자마다 1개**, 글당 4~9개. 소제목 일부에 핵심·연관 키워드를 자연스럽게 |
| 소제목 형태 | 질문형("~할까요?")과 단정형("~입니다")을 섞음. 질문형 검색과 AI 브리핑 대응에 유리하다는 관찰이 많음 |
| 문단 | **모바일 기준 2~5줄**. 한 문단에 한 가지 이야기 |
| 구조화 | 비교는 표, 절차는 번호 목록, 조건은 불릿 |
| FAQ | 글 끝에 질문 2~4개. 실제로 검색할 법한 문장으로 |
| 결론 | 핵심 요약 1~2문장 + 독자가 바로 할 수 있는 행동 |
| 외부 링크 | 공식 출처 위주로 소수. 상업 링크 남발 금지 |

(도입 10~15%)

- 이 글이 답하는 질문 + 한 줄 결론  ← 핵심 키워드 1회

(결론 10%)

## 4. 키워드 밀도와 배치

### 4-1. 네이버가 공식적으로 밝힌 것 [공식]
- **밀도·횟수 기준은 발표된 적이 없습니다.**
- 검색 노출을 위해 **유사한 키워드를 반복적으로 사용하는 행위**는 어뷰징입니다. (2024)
- 노출만을 위해 **맥락 없는 키워드를 끼워 넣은 글**은 '외면받는 글'입니다. (2026-05)
- **동일 키워드의 의도적 반복**은 스팸 유형입니다. (2026-07)
- D.I.A.+는 검색 데이터로 **유의어를 확장**해 문서를 이해합니다. 같은 단어를 반복하지 않아도 뜻이 통하면 매칭될 수 있습니다. (2차 설명)

### 4-2. 실무 권장 [업계]
- "키워드 밀도 1~2%"는 **구글 SEO에서 온 숫자**로, 네이버 근거가 없습니다.
- 배치는 **위치 중심**으로 생각합니다. 횟수를 세기보다 아래 자리에 한 번씩 자연스럽게 있는지 확인합니다.

| 위치 | 핵심 키워드 | 연관·세부 키워드 |
|---|---|---|
| 제목 | 1회 (앞쪽) | 0~1회 |
| 도입 첫 3~5줄 | 1회 | — |
| 소제목 | 전체 소제목 중 1~2개 | 2~3개 |
| 본문 | 문맥상 필요한 곳에만 (2,000자 기준 2~4회) | 고르게 분산 |
| 결론 | 1회 | — |
| 이미지 캡션 | 필요할 때 0~1회 | 0~1회 |
| 태그 | 1회 | 2~4개 |

**총량 감각**: 공백 제외 2,000자 글에서 핵심 키워드가 **4~7회** 안팎이면 대개 자연스럽습니다. 이것도 숫자를 맞추라는 뜻이 아니라, 이보다 훨씬 많으면 반복을 의심해 보라는 기준입니다.

### 4-3. 배치 규칙
1. **한 문단에 같은 키워드 2번 이상 쓰지 않습니다.** 두 번째부터는 대명사("이 방법"), 유의어, 줄임말로 바꿉니다.
2. **연관 키워드 묶음**을 미리 정합니다: 핵심 키워드 1개 + 세부 키워드 3~5개 + 유의어 2~3개.
   - 예: 핵심 "재구매율" / 세부 "재구매율 높이는 법", "재구매 주기", "첫 구매 쿠폰" / 유의어 "재주문률", "두 번째 구매"
3. 키워드를 넣으려고 **문장을 어색하게 비틀지 않습니다.** 소리 내어 읽어 어색하면 뺍니다.
4. 키워드를 **굵게 표시하거나 색을 바꿔 반복 강조하지 않습니다.**
5. **숨긴 텍스트**(흰 글씨, 아주 작은 글씨로 키워드 넣기)는 절대 쓰지 않습니다. 웹마스터 가이드상 스팸입니다. **[공식]**

## 5. 이미지

### 5-1. 네이버가 공식적으로 밝힌 것 [공식]
- **맥락에 맞는 이미지와 동영상**을 씁니다. (2026-06 셀프 체크 ⑤)
- **콘텐츠와 무관한 이미지·동영상**은 '외면받는 글' 유형입니다. (2026-05)
- 이미지로 전달하는 **핵심 정보는 텍스트로도 함께** 씁니다. (서치어드바이저 웹 가이드도 중요한 정보를 이미지 안에만 두지 말라고 안내)
- AI로 생성·편집한 이미지에는 **'AI 활용' 표시를 권장**합니다. 블로그는 자율이며, 표시하지 않아도 제재는 없습니다. (2025-05 기능 도입, 2026-07 보도)
- 실제처럼 보여 **사람을 속일 수 있는 생성 이미지**는 피해 유발 콘텐츠로 봅니다. (2026-07)
- 다른 사람의 사진을 복사해 쓰는 것은 독창성 원칙에 어긋납니다. (2024, "다른 문서를 복사하거나 짜깁기하지 않고")

### 5-2. 장수 [업계]
- **공식 기준은 없습니다.** "사진 15장 이상"은 예전 업계 공식이고, 지금은 근거 없다는 의견이 많습니다.
- 실무 권장: **정보 전달에 필요한 만큼, 대략 본문 300~600자마다 1장, 글당 5~15장.**
- 후기·체험 글은 직접 찍은 사진이 많을수록 경험 정보가 풍부해 보입니다. 정보·칼럼형 글은 표·도식 3~6장으로도 충분합니다.
- 같은 이미지를 여러 글에 재사용하거나, 무료 스톡 이미지로 채우는 것은 피합니다. (유사 문서로 판단될 수 있다는 통설)
- **본문 전체를 텍스트 이미지로 만들지 않습니다.** 검색이 이미지 속 글자를 본문만큼 이해하지 못합니다.

### 5-3. alt 텍스트(대체 텍스트)
- 네이버 블로그 에디터(스마트에디터 ONE)에서 이미지 alt를 직접 입력하는 공식 기능이나, 그 값이 검색에 반영된다는 공식 안내는 **이번 리서치에서 확인하지 못했습니다.** **[확인 불가]**
- 그래서 네이버 블로그에서는 다음으로 대신합니다. **[업계]**
  1. **사진 설명(캡션)**에 이미지가 무엇을 보여 주는지 한 문장으로 씁니다. 필요하면 키워드를 자연스럽게 0~1회 넣습니다.
  2. 이미지 바로 앞이나 뒤 본문에서 이미지 내용을 텍스트로 다시 설명합니다.
  3. 파일명을 의미 있게 짓습니다(예: `repurchase-rate-table.png`). 효과는 크지 않다는 의견이 많지만 손해는 없습니다.
- **자체 웹사이트 블로그**(예: 회사 홈페이지 블로그)라면 alt를 반드시 씁니다. 형식: `[이미지 제목] - [이미지가 보여 주는 핵심]`, 125자 이내. 장식용 이미지는 `alt=""`.

### 5-4. 대표 이미지(썸네일) [업계]
- 따로 지정하지 않으면 **본문 맨 위 이미지**가 대표 이미지가 됩니다. **직접 지정**하는 것이 안전합니다.
- 검색 결과와 피드에서 **정사각형 등으로 잘려 보일 수 있습니다.** 핵심 피사체와 글자는 **가운데**에 둡니다.
- 글자를 넣는다면 **짧고 크게**(한 줄 10자 안팎). 모바일 작은 화면에서도 읽혀야 합니다.
- 제목과 내용이 맞아야 합니다. 본문에 없는 장면이나 과장된 문구는 낚시성으로 보입니다.
- **직접 찍거나 직접 만든 원본**을 씁니다. 다른 글에서 쓴 대표 이미지나 남이 만든 템플릿을 그대로 반복하지 않습니다.
- 첫 화면에서 글의 성격(후기인지, 정보 정리인지)이 바로 보이게 합니다.

## 6. 해시태그

### 6-1. 근거 현황
- 네이버가 태그와 검색 순위의 관계를 공식적으로 밝힌 자료는 **확인하지 못했습니다.** **[확인 불가]**
- 업계 의견은 엇갈립니다. "태그는 검색 순위에 직접 영향이 거의 없다"는 의견이 많고, "본문과 무관한 태그는 신뢰도에 불리하다"는 의견도 있습니다. **[업계]**
- 본문과 관련 없는 키워드를 넣는 것은 공식 '외면받는 글' 원칙(무관한 키워드 삽입)에 해당할 수 있으므로, 태그에도 같은 기준을 적용합니다. **[공식 원칙을 준용]**

### 6-2. 실무 권장 [업계]
- 태그는 **최대 30개**까지 달 수 있는 것으로 알려져 있습니다. 하지만 **5~10개**만 씁니다.
- 구성 예:

| 종류 | 개수 | 예 (주제: 재구매율) |
|---|---|---|
| 핵심 키워드 | 1 | #재구매율 |
| 세부·롱테일 키워드 | 2~4 | #재구매율높이는법 #첫구매쿠폰 #재구매주기 |
| 카테고리·분야 | 1~2 | #쇼핑몰운영 #이커머스마케팅 |
| 브랜드·고유명사 | 0~1 | #(본인 브랜드명) |
| 상황·대상 | 0~2 | #쇼핑몰대표 |

- 띄어쓰기 없이 붙여 씁니다.
- 글마다 똑같은 태그 묶음을 복사해 붙이지 않습니다. 글 내용에 맞게 바꿉니다.
- 인기 태그를 본문과 상관없이 넣지 않습니다.
- 본문 안에 `#태그`를 문장마다 넣지 않습니다. 본문 해시태그는 쓰더라도 글 끝에 모읍니다.
- 태그 목록 화면에 글이 모여 보이는 기능이 있으므로, 브랜드명·매장명 같은 고유명사는 넣어 두면 좋습니다.

## 7. C-Rank와 D.I.A.가 좋아하는 패턴

### 7-1. C-Rank: 출처(블로그)를 평가 [공식]
- 2016년 도입. 글 하나가 아니라 **블로그라는 출처의 신뢰도와 인기도**를 평가합니다.
- 평가 요소 (네이버 고객센터 설명 기준):

| 요소 | 뜻 | 좋아하는 패턴 |
|---|---|---|
| **Context** (맥락) | 관심 주제에 얼마나 집중하는가 | 블로그 하나에 주제 하나. 카테고리를 주제 중심으로 정리. 주제와 무관한 글(일상, 광고 대행 글 등) 섞지 않기 |
| **Content** (내용) | 생산하는 정보의 품질 | 경험과 분석이 있는 충실한 글을 꾸준히. 복사·짜깁기 0 |
| **Chain** (연결) | 콘텐츠가 소비되고 다시 생산되는 연쇄 반응 | 공감·댓글·스크랩·재방문, 다른 곳에서 인용·공유되는 글. 댓글에 성실히 답하기 |

- 네이버는 C-Rank 점수나 등급을 공개하지 않고, **필요한 글 수·발행 빈도·운영 기간 같은 숫자 기준도 밝히지 않았습니다.** **[공식]**
- "블로그 지수"라는 단일 점수가 노출을 결정한다는 말은 공식 근거가 없습니다. **[업계 통설]**

### 7-2. D.I.A.: 문서(글 한 편)를 평가 [공식]
- 2018년 적용. 검색어별로 **사용자가 선호하는 문서**의 특징을 학습해 점수를 매깁니다.
- 평가 요소와 좋아하는 패턴:

| 요소 | 좋아하는 패턴 |
|---|---|
| 주제 적합도 | 제목·소제목·본문이 검색어의 의도에 정확히 답함 |
| 경험 정보 | 직접 써 보고, 가 보고, 해 본 내용. 날짜·장소·기간·수치·사진 |
| 정보의 충실성 | 절차, 비교, 조건, 주의점까지 빠짐없이 |
| 문서의 의도 | 정보 전달이 목적. 광고·홍보가 앞서지 않음 |
| 독창성 | 다른 글에 없는 관점·데이터·사례 |
| 적시성 | 최신 정보. 바뀐 정보는 수정 |
| (상대적인 어뷰징 척도) | 키워드 반복·복사 등 어뷰징 신호가 적음 (2차 자료 기준) |

- **D.I.A.+**: 딥러닝 기반 질의 해석과 유의어 확장을 더한 후속 버전으로 소개됩니다. 키워드를 똑같이 반복할 필요가 줄었다는 뜻입니다. **[공식-2차 설명]**

### 7-3. 두 알고리즘과 AI 브리핑을 한 번에 만족시키는 체크
- [ ] 이 블로그의 주제와 맞는 글인가 (Context)
- [ ] 직접 경험이나 직접 측정한 내용이 있는가 (경험 정보, 5원칙 ①)
- [ ] 셀프 체크 5항목(독자·절차·비교·결과·맥락 이미지)을 채웠는가 (충실성)
- [ ] 다른 글에 없는 관점이나 데이터가 있는가 (독창성)
- [ ] 결론이 앞에 있고, 소제목과 표로 훑어 읽을 수 있는가 (5원칙 ④, AI 브리핑)
- [ ] 정보가 최신이고, 출처가 분명한가 (적시성, 진정성)
- [ ] 홍보보다 정보가 앞서는가 (문서의 의도)
- [ ] 공감·댓글·저장하고 싶을 만큼 쓸모 있는가 (Chain)

### 7-4. 운영 패턴 [공식]+[업계]
- **최신성 유지**: 정보가 바뀌면 기존 글을 수정하고, 새 글을 꾸준히 씁니다. **[공식]** 글을 수정하면 불이익이 있다는 말은 네이버가 공식 부정한 소문입니다. **[공식]**
- **발행 빈도**: 공식 기준은 없습니다. 하루 발행 수 제한이나 특정 발행 시간이 유리하다는 말도 근거가 없습니다. 다만 짧은 글을 짧은 시간에 몰아 올리는 것은 저품질 신호로 여겨집니다. 일정한 주기(예: 주 2~4회)로 충실한 글을 올리는 것을 권합니다. **[업계]**

## 8. 어뷰징으로 판정되는 것들 (피해야 할 것)

### 8-1. 네이버 공식 목록 [공식]

**2024-02 생성형 AI 정책의 어뷰징 예시**
- 다른 문서를 단순 복사하거나, 검색 노출을 위해 유사한 키워드를 반복 사용하는 행위
- 생성형 AI로 문맥이 이어지지 않는, 가독성 낮은 콘텐츠를 반복 생성하는 행위
- 동일·유사한 콘텐츠를 생성형 AI로 대량 생산하는 행위
- 뉴스·웹사이트·블로그 등 다른 사람의 콘텐츠를 복사·짜깁기해 생성형 AI로 자동 대량 생산하는 행위

**2026-05 '외면받는 글' 5유형**
- 무분별한 복제와 생성
- 과도한 광고와 홍보
- 노출만을 위한 무관한 키워드 삽입
- 콘텐츠와 무관한 이미지·동영상
- 부정확하고 부적절한 정보

**2026-07 '웹 콘텐츠 스팸 사례' 중 확인된 유형**
- 동일 키워드의 의도적 반복
- 실제 명칭 대신 검색량이 많은 키워드 사용
- 제목과 내용이 일치하지 않는 낚시성 제목
- 저품질 대량 생성 (특정 기술을 썼는지가 아니라 대량 생성 행위 자체로 판단)
- 실제로 오인될 수 있는 생성 이미지 등 피해 유발 콘텐츠
- ※ 전체 목록은 원문을 직접 확인하지 못했습니다.

**2016 블로그 글쓰기 안내·웹마스터 가이드**
- 의미 없는 특수문자·유니코드로 주목도를 높이는 행위
- 본문과 무관한 업체명·문구를 넣은 낚시성 문서
- **클로킹**: 검색 로봇과 실제 방문자에게 다른 내용을 보여 주기
- **링크 스팸**: 링크만 모은 페이지, 다른 사이트 취약점을 이용한 대량 링크
- **숨긴 텍스트**: 배경색과 같은 글씨, 아주 작은 글씨로 키워드 넣기
- 피싱·악성 코드가 있는 문서

### 8-2. 업계에서 어뷰징 신호로 보는 패턴 [업계]
공식 문서에 같은 표현은 없지만, 위 공식 원칙에 비춰 위험하다고 널리 여겨지는 것들입니다.
- 같은 글이나 거의 같은 글을 여러 블로그·여러 날짜에 올리기
- 다른 사람의 사진이나 같은 사진을 여러 글에 재사용하기
- 300자 안팎의 짧은 글을 하루에 여러 개 올리기
- 매크로·프로그램으로 공감·댓글·스크랩·이웃 추가하기, 품앗이 공감
- 블로그 계정 매매·대여, 남의 블로그에 원고 대리 발행
- 광고·협찬 글 비중이 지나치게 높아지기
- 본문 곳곳에 상업 링크·연락처·쿠폰 코드 반복
- 본문을 통째로 이미지로 만들어 올리기

### 8-3. 자동화 관련 주의 (이 프로젝트에 특히 중요)
- **사람의 검수 없이 AI로 생성하고 프로그램으로 자동 발행하는 방식**은 2024년 어뷰징 예시, 2026년 스팸 유형에 모두 해당할 수 있습니다. 네이버 이용약관에도 자동화 수단 사용을 제한하는 조항이 있다고 알려져 있습니다. **[공식 원칙 + 2차 해석]**
- 안전한 방식은 다음과 같습니다.
  1. AI로 초안과 구조를 만듭니다.
  2. 사람이 **실제 경험, 실제 수치, 사실 확인**을 더합니다.
  3. 사람이 직접 발행합니다.
  4. AI 생성 이미지에는 'AI 활용' 표시를 합니다. 글 자체도 AI를 활용했다면 명시를 권장합니다. **[공식]**
- 비슷한 구조의 글을 대량으로 찍어 내지 않도록, 주제와 사례를 매번 새로 고릅니다.

### 8-4. 법적 기준: 협찬·광고 표시 [법규]
- 2024-12-01 시행된 공정위 「추천·보증 등에 관한 표시·광고 심사지침」 개정에 따라, 블로그는 **제목 또는 본문 첫 부분**에 경제적 이해관계를 밝혀야 합니다.
- 본문과 구분되게(글자 크기를 키우거나 색을 다르게) 표시합니다. "더보기"처럼 추가로 눌러야 보이는 위치는 안 됩니다.
- "소정의 수수료를 받을 수 있음" 같은 모호한 문구는 쓸 수 없습니다.
- 판매 실적에 따라 수수료를 받는 제휴 링크, 체험단, 미래·조건부 대가(우수 후기 선정 등), 고용·친족 관계도 표시 대상입니다. (2025-12-02 안내서 개정)

### 8-5. 근거 없는 소문 (믿지 말 것)

| 소문 | 사실 |
|---|---|
| 블로그 지수라는 단일 점수가 노출을 정한다 | 공식 근거 없음. 네이버는 C-Rank 점수를 공개하지 않음 |
| 글을 수정하면 불이익이 있다 | 네이버가 2016년 공식 부정 |
| 제목에 특수문자를 넣으면 상위 노출된다 | 사실과 다른 소문으로 정리됨 |
| 1,500자·사진 15장·키워드 5회를 맞추면 된다 | 공식 기준 없음. 예전 업계 공식 |
| 하루에 N개 넘게 올리면 저품질이 된다 | 숫자 기준은 근거 없음. 다만 짧은 글 대량 발행은 위험 |
| 특정 시간에 올려야 잘 뜬다 | 근거 없음 |
| AI로 쓴 글은 무조건 검색에서 빠진다 | 공식 부정. 품질이 기준 |

## 9. style-guide.md와 함께 쓸 때

`style-guide.md`는 회사 웹사이트 블로그 문체를 분석한 것입니다. 네이버 블로그에 올릴 글에 적용할 때는 아래를 확인합니다.

| style-guide 요소 | 네이버 SEO 관점 | 조치 |
|---|---|---|
| 제목 `[개념]이란? [부제]` | 핵심 키워드가 앞에 오고 1회 → 잘 맞음 | 그대로 사용. 공백 포함 35자를 넘으면 부제를 줄임 |
| 도입부 셀프 체크 + 형광펜 명제 | 결론이 앞에 있어 두괄식에 맞음 | 형광펜 명제나 그 앞 문장에 핵심 키워드 1회 |
| 한 줄 한 문장, 3~6줄 문단 | 모바일 가독성 → 잘 맞음 | 그대로 |
| H2 8~9개, 정의형 첫 H2 | 소제목 구조 → 잘 맞음 | 소제목 1~2개에 핵심 키워드, 나머지는 연관 키워드 |
| 가상 예시 고지 | 진정성 원칙 → 잘 맞음 | 그대로 |
| 가상 예시 위주 | 경험 정보가 약해질 수 있음 | **실제 경험·실제 수치 1~2개**를 더함 (셀프 체크 ④) |
| 표 인포그래픽 3장 | 본문에서 먼저 설명한 내용을 요약 → 텍스트 병기 원칙에 맞음 | 직접 제작 원본 사용. 캡션 유지. 대표 이미지는 별도 지정 |
| FAQ 3개 | 질문형 검색 대응 → 잘 맞음 | 질문을 실제 검색어에 가깝게 |
| 사이트 CTA 블록 | 홍보가 과하면 '과도한 광고' 유형 | 링크·연락처는 글 끝 1회만 |
| 형광펜·메모 박스 | 네이버 에디터에 같은 기능이 없음 | 형광펜 → 글자 배경색, 메모 박스 → 인용구, 소제목 → 에디터 '소제목' 서식 |
| 태그 | style-guide에 없음 | 6장 기준으로 5~10개 추가 |

## 10. 발행 전 최종 체크리스트

**제목**
- [ ] 핵심 키워드가 앞쪽에 1회만 있다
- [ ] 공백 포함 20~35자 안팎이다
- [ ] 키워드 나열, 장식 특수문자, 과장 표현, 무관한 고유명사가 없다
- [ ] 본문이 제목의 약속을 지킨다

**본문**
- [ ] 첫 3~5줄에 이 글의 질문과 결론이 있다 (핵심 키워드 1회)
- [ ] 소제목이 400~600자마다 있고, 문단은 2~5줄이다
- [ ] 셀프 체크 5항목(독자·절차·비교·결과·맥락 이미지)을 채웠다
- [ ] 직접 경험이나 직접 측정한 내용이 1개 이상 있다
- [ ] 한 문단에 같은 키워드가 2번 이상 나오지 않는다
- [ ] 출처가 분명하고 정보가 최신이다
- [ ] 홍보·링크가 과하지 않다

**이미지**
- [ ] 본문 맥락에 맞는 직접 촬영·제작 원본이다
- [ ] 이미지 속 핵심 정보를 본문 텍스트로도 썼다
- [ ] 캡션에 이미지가 보여 주는 내용을 한 문장으로 썼다
- [ ] 대표 이미지를 직접 지정했고, 가운데에 핵심이 있다
- [ ] AI 생성·편집 이미지에는 'AI 활용' 표시를 했다

**태그와 기타**
- [ ] 본문과 관련된 태그 5~10개
- [ ] 협찬·광고라면 제목이나 첫 부분에 표시했다
- [ ] 블로그 주제와 맞는 글이다
- [ ] 사람이 검수하고 직접 발행한다
