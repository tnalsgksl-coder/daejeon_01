# 블로그 자동화 프로젝트

## 블로그 글 작성 규칙

블로그 글을 작성하라는 지시를 받으면(새 글, 재작성, 수정 모두 포함) **글을 쓰기 전에 아래 두 파일을 반드시 먼저 읽고**, 그 기준에 맞춰 작성한다.

1. `style-guide.md` — 말투, 문체, 글 구조, 강조, 이미지 배치 패턴
2. `SEO-guide.md` — 네이버 블로그 SEO 규칙 (제목, 본문 구조, 키워드, 이미지, 해시태그, 어뷰징 금지)

### 작성 순서
1. 두 파일을 처음부터 끝까지 읽는다. 이전에 읽었더라도 매번 다시 읽는다(파일이 수정됐을 수 있음).
2. 두 파일의 기준이 부딪히면 `SEO-guide.md` 9장("style-guide.md와 함께 쓸 때")의 조치를 따른다.
3. 글을 쓴다.
4. `style-guide.md` 14장(작성 후 셀프 점검표)과 `SEO-guide.md` 10장(발행 전 최종 체크리스트)으로 점검하고, 통과하지 못한 항목은 고친 뒤 결과를 짧게 보고한다.

### 지킬 것
- 두 파일 중 하나라도 없거나 읽을 수 없으면 글을 쓰지 말고 먼저 알린다.
- 실제 경험, 실제 수치, 실제 사례는 지어내지 않는다. 필요한 정보가 없으면 사용자에게 묻거나 `[확인 필요]`로 표시한다. 설명용 숫자는 style-guide 규칙대로 "가상 예시"라고 밝힌다.
